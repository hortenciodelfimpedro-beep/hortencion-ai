# Contribuindo para Hortêncio AI

Obrigado por se interessar em contribuir! Aqui estão as diretrizes:

## 🐛 Encontrou um Bug?

- Verifique se o bug já foi reportado em Issues
- Se não encontrar, abra uma nova issue com:
  - Título descritivo
  - Descrição clara do problema
  - Passos para reproduzir
  - Comportamento esperado vs atual
  - Screenshots (se aplicável)
  - Seu ambiente (OS, versões, etc.)

## ✨ Sugerindo Melhorias

- Use o label "enhancement" ao abrir uma issue
- Descreva claramente o caso de uso
- Liste exemplos de aplicações similares

## 📝 Pull Requests

1. **Fork o repositório**
2. **Crie uma branch** (`git checkout -b feature/sua-feature`)
3. **Faça seus commits** com mensagens claras
4. **Push para a branch** (`git push origin feature/sua-feature`)
5. **Abra um PR** com descrição detalhada

### Checklist do PR

- [ ] Testes adicionados/modificados
- [ ] Documentação atualizada
- [ ] Nenhuma quebra de mudanças não documentadas
- [ ] Código segue o estilo do projeto
- [ ] Sem credenciais ou dados sensíveis

## 🎨 Guia de Estilo

### Python
- PEP 8 compliance
- Type hints obrigatórios
- Docstrings em todas as funções públicas

### JavaScript/TypeScript
- ESLint config do projeto
- Prettier para formatação
- TSLint para TypeScript

### Commits
- Use mensagens descritivas
- Prefixos: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`
- Exemplo: `feat: adiciona ferramenta de busca no Drive`

## 🔒 Segurança

- **NUNCA** commit credenciais ou tokens
- Use variáveis de ambiente
- Revise permissões antes de PR
- Siga princípio de menor privilégio

## ❓ Dúvidas?

- Abra uma Discussion no repositório
- Consulte a documentação em `docs/`
- Entre em contato via Issues

Obrigado por contribuir! 🙏
